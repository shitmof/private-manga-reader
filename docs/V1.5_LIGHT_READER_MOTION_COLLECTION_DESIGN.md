# 拾画阁 V1.5：白蓝阅读器、统一动效与动态书单设计规格

> 文档性质：下一版本新增功能与视觉交互实施基线
>
> 建议目标版本：`v1.5.0`
>
> 编写日期：2026-08-31
>
> 当前状态：设计确认稿，尚未进入代码实施
>
> 视觉边界：保留 V1.4 的整体框架、信息结构、蓝白品牌和三列书架，只升级阅读器、动效、书单容器与栅格节奏

## 0. 结论

V1.5 不再重做产品框架，而是让现有结构从“功能能用”提升到“视觉统一、动作自然、集合清楚”。

本轮只处理三个核心问题：

1. **阅读器从黑色工具界面改为拾画阁白蓝阅读舞台。** 本地漫画、网络挂载漫画、加载、错误、设置、放大页和页码提示使用同一套颜色。
2. **建立一套统一动效规则。** 打开、返回、长按抬起、拖动、换位、合组、取消和完成都有连续过渡，卡片不再突然缩小或瞬间跳位。
3. **把书单做成真正的动态白色集合卡。** 参考用户提供截图中“四张封面收在一个白色容器内”的组织方式，但继续使用拾画阁蓝色，不复制番茄小说的橙色、广告、导航或商业模块。

一句话效果：

> 阅读页像一张安静的白色画纸；书架像整齐的私人画册墙；两本漫画合组时，卡片自然聚拢进一张白色四宫格书单，而不是突然缩进去或弹出割裂的系统对话框。

## 1. 用户口语需求的标准化解释

| 用户表达 | 产品化定义 | 本轮交付 |
|---|---|---|
| “继续阅读之后整体偏黑” | 阅读器硬编码了深黑背景、深色工具栏、深色设置面板和黑色放大页，与主应用白蓝主题割裂 | 阅读器全状态白蓝化，并保留可选夜间阅读 |
| “移动直接拖进去，很僵硬” | 拖动反馈尺寸固定、目标卡片瞬间缩放、排序使用跳变，缺少连续空间关系 | 拖动抬升、跟手、让位、吸附、回弹、聚合动效 |
| “缩进去很难受” | 合组候选只有目标卡片缩小和蓝色遮罩，源卡片没有连续进入容器的视觉路径 | 使用共享拖动层完成源卡片到四宫格槽位的形态过渡 |
| “合成书单界面很怪” | 当前使用通用 `AlertDialog + TextFormField`，与书架卡片缺少视觉联系 | 改为动态白色合组确认面板，直接预览合组后的四宫格结果 |
| “参考番茄小说的书单效果” | 吸收白色集合容器、四封面预览、统一三列节奏和标题/数量对齐 | 形成拾画阁自己的白蓝集合卡，不复制品牌界面 |
| “漫画间距重、很短” | 当前卡片只显示一行标题，`childAspectRatio: 0.57` 使内容显得短促；9dp 横间距与 18dp 行距缺少统一节奏 | 封面比例、两行标题、元信息、横纵间距统一重排 |
| “隔层也按这样排版” | 本文解释为主书架书单以及进入书单后的漫画层级 | 根书架和书单内部复用同一三列栅格，不出现另一套密度 |

若“隔层”实际指其他页面，后续实施前只需补充目标页面；本文件不借此扩大功能范围。

## 2. 参考图取舍

### 2.1 吸收的部分

- 三列封面宽度统一，普通漫画与集合卡占用相同格位。
- 集合卡使用白色圆角底板，内部固定 2×2 封面预览。
- 标题和数量位于封面区下方，视觉起点一致。
- 行与行之间保留明显呼吸空间，标题允许两行，信息不挤在封面底部。
- 集合在书架中直接可见，不需要进入“分组管理”页面寻找。

### 2.2 不吸收的部分

- 不复制橙色强调色，统一使用拾画阁蓝色。
- 不增加书城、广告、签到、会员、推荐值、出版筛选等商业模块。
- 不照搬番茄小说的字体、品牌图标、导航结构和文案。
- 不把漫画章数概念强加给图片漫画；继续显示“张数、体积、阅读进度”。
- 不为了视觉动效上传封面或读取网络推荐数据。

## 3. 总体视觉方向

### 3.1 关键词

```text
画纸感 / 清透白 / 克制蓝 / 轻悬浮 / 连续运动 / 私人画册
```

### 3.2 颜色令牌

| 用途 | 色值 | 说明 |
|---|---|---|
| 页面底色 `paper` | `#F7F8FA` | 主书架与阅读器外层画纸色 |
| 主表面 `surface` | `#FFFFFF` | 卡片、书单、弹层、阅读控制栏 |
| 主文字 `ink` | `#17202B` | 标题与主要按钮 |
| 次文字 `muted` | `#6D7784` | 张数、体积、提示 |
| 品牌蓝 `blue` | `#2D75C7` | 选中、滑轮、主要操作 |
| 亮蓝 `blueSoft` | `#EAF2FC` | 候选态、空槽、轻提示 |
| 结构线 `line` | `#E5E9EE` | 1dp 边框和必要分隔 |
| 浮层遮罩 | `#17202B` 12% | 合组确认时的背景压暗 |
| 阴影 | `#173A63` 8% | 白色卡片的低饱和阴影 |

禁止出现大面积纯黑作为默认阅读器背景。纯黑只允许用于用户主动选择的“夜间阅读”或图片放大时明确选择的黑底模式。

### 3.3 圆角与阴影

- 漫画封面：12dp 圆角。
- 书单白色容器：16dp 圆角。
- 合组确认面板：顶部 24dp 圆角。
- 页码胶囊：16dp 圆角。
- 静止卡片不使用重阴影；白色书单使用 `0 4 14`、8% 阴影和 1dp 结构线。
- 拖动卡片临时提升到 `0 10 28`、14% 阴影，松手后恢复。

## 4. 白蓝阅读器

### 4.1 默认阅读舞台

```text
┌──────────────────────────────┐
│ ‹  夏日的午后       书签  设置  ⋯ │  白色浮层，蓝色图标
├──────────────────────────────┤
│                              │
│          漫画原图             │  白色图片画布
│                              │
│          漫画原图           ▏ │  触碰右侧才显示蓝色滑轮
│                              │
│            [156 / 628]        │  白底蓝字页码胶囊
└──────────────────────────────┘
```

默认规则：

- `Scaffold` 使用 `paper`，每张图片承载面使用 `surface`。
- 顶部控制栏使用 96% 不透明白色，不使用深黑背景；图标使用 `blue`，标题使用 `ink`。
- 顶部控制栏只覆盖图片，不推动漫画内容。
- 状态栏使用浅色背景和深色系统图标；导航栏与 `paper` 一致。
- 加载指示器使用品牌蓝；损坏图片使用 `blueSoft` 底和 `muted` 图标。
- 本地阅读器与挂载阅读器必须共享相同组件，不允许两套颜色继续分叉。

### 4.2 页码与纵向滑轮

- 页码胶囊：白底、蓝字、1dp `line` 边框、轻阴影，不恢复横向 Slider。
- 右侧滑轮空闲时仍然完全不可见，保留 V1.4 的 48dp 隐形热区。
- 触碰后轨道使用品牌蓝 18%，滑块使用 `blue`，拖动页码浮标使用白底蓝字。
- 松手约 1.1 秒后轨道、滑块和提示整体淡出。
- 滑轮出现/隐藏只改变透明度和 4dp 水平位移，不改变漫画布局。

### 4.3 阅读设置面板

当前深灰底部面板改为白色：

- 白色表面，顶部 24dp 圆角，拖动柄使用 `line`。
- 标题 `ink`，说明 `muted`，Slider 轨道和选中态使用 `blue`。
- 书签 Chip 使用 `blueSoft` 背景和 `blue` 文字。
- 弹出 220ms，关闭 180ms；背景遮罩最高 12%，不把阅读页压成黑色。

### 4.4 放大页

- 默认放大页背景采用 `paper`/`surface`，顶部栏白蓝化。
- 设置中保留“放大背景：白色 / 黑色”选项，黑色不是默认值。
- 从阅读图片进入放大页时使用同一张图片的 Hero 过渡，避免先闪黑再出现图片。

### 4.5 夜间阅读边界

- 应用深色主题不能自动强制阅读页变黑。
- 阅读设置增加独立选项：`阅读背景：跟随画纸 / 夜间黑色`。
- 升级后默认值为“跟随画纸”；已有图片、进度、书签和亮度设置不变。

## 5. 三列书架栅格重排

### 5.1 栅格尺寸

手机竖屏的基准规格：

| 项目 | 规格 |
|---|---|
| 页面左右留白 | 16dp |
| 列数 | 3 |
| 列间距 | 14dp |
| 行间距 | 24dp |
| 封面宽高比 | 0.72（宽 / 高） |
| 封面圆角 | 12dp |
| 封面到标题 | 10dp |
| 标题 | 14sp、两行、行高 1.3 |
| 标题到元信息 | 5dp |
| 元信息 | 11.5sp、单行 |
| 卡片点击热区 | 覆盖封面、标题和元信息，最小 48dp |

实现时不再用单一 `childAspectRatio` 猜测总高度。卡片高度由以下结构计算：

```text
封面高度 = 卡片宽度 / 0.72
总高度   = 封面高度 + 10 + 两行标题高度 + 5 + 元信息高度
```

这样可以解决当前“一行标题导致卡片短促、漫画块挤在一起”的问题，同时保证普通漫画和书单始终等高。

### 5.2 标题与元信息

- 漫画标题最多两行，超出后省略。
- 普通漫画元信息：`628 张 · 1.8 GB`；已经阅读时可显示 `读到第 156 张`，二者择一，不堆两行小字。
- 书单元信息：`共 15 本`。
- 更多菜单固定占用元信息行右侧 24dp，不能因为有无菜单导致标题区错位。
- 置顶、私密、选中标志继续覆盖在封面上，不额外增加卡片高度。

### 5.3 自适应

- 小于 340dp 宽：左右留白 12dp、列间距 10dp，仍保持三列。
- 340～599dp：按上述 16/14dp 基准。
- 600dp 及以上：可以切为 4～5 列，但单卡宽度保持 104～132dp，不无限放大。
- 横屏和平板只增加列数，不把集合卡拉成长横条。

## 6. 动态白色书单

### 6.1 静止状态

书单与普通漫画占用相同格位和相同总高度：

```text
┌────────────────┐
│  ┌────┐ ┌────┐ │
│  │封面│ │封面│ │
│  └────┘ └────┘ │
│  ┌────┐ ┌────┐ │
│  │封面│ │封面│ │
│  └────┘ └────┘ │
└────────────────┘
想看的漫画
共 15 本                 ⋮
```

视觉规格：

- 外层为白色圆角容器，不再使用大面积蓝色底板。
- 容器边框 1dp `line`，阴影轻微；按下时阴影收紧，产生纸卡触感。
- 内边距 8dp，四格间距 4dp，内部封面圆角 5dp。
- 不足四本时，空位使用 `blueSoft` 8%～35% 的淡蓝画纸，不显示突兀的大文件夹图标。
- 超过四本只显示书单内排序最前的四本，不叠加第五本。
- 私密书单锁定时不显示真实封面：四格统一为淡蓝占位，并在中心显示小锁。

### 6.2 进入书单

- 点击书单时，白色容器以 280ms 从原格位扩展为页面顶部的书单标题区。
- 四张封面在扩展过程中保持位置连续，随后 40ms 间隔依次淡入书单内部三列网格。
- 进入后的漫画仍使用第 5 节的同一套三列规格，不切换到更密或更宽的布局。
- 系统返回执行完全相反的收拢动画；返回完成前不响应第二次打开。

### 6.3 空书单和单本书单

- 书单为空时仍保留白色四宫格容器，四格均为空纸槽，元信息显示 `空书单`。
- 书单只剩一本时不自动解散，第一格显示真实封面，其余三格为空槽。
- 删除书单仍需二次确认；默认只解散归位，不删除漫画。

## 7. 合成书单的新交互

### 7.1 拖动候选

漫画 A 长按拖向漫画 B：

1. A 在 150ms 内抬升到 1.035 倍，阴影增加，但反馈卡尺寸必须与原卡一致，不能突然变成固定的 112×196。
2. A 跟随手指；原位置保留淡蓝虚线占位，避免其他卡片瞬间塌缩。
3. A 经过卡片边缘时只显示蓝色插入线，其他卡片用 220ms 平滑让位。
4. A 进入 B 中央后，B 不再缩到 0.92；改为轻微放大到 1.02，并在外围出现淡蓝呼吸边框。
5. 停留 550ms 后产生一次中等触感，B 的封面向四宫格右上槽轻移，A 的缩略预览对准左上槽，明确表达“即将形成集合”。

### 7.2 松手后的确认面板

弃用通用 `AlertDialog`，改为底部动态白色确认面板：

```text
╭──────────────────────────────╮
│          合成书单             │
│  ┌────────────────────────┐  │
│  │ [漫画A] [漫画B] [空] [空] │  │
│  └────────────────────────┘  │
│  书单名称                    │
│  [ 新建书单                ] │
│                              │
│  [取消]          [合成书单]  │
╰──────────────────────────────╯
```

- 面板从底部上移 24dp 并淡入，280ms 完成；背景只压暗 12%。
- 顶部预览必须是真实的白色四宫格书单，而不是两个孤立封面加文字说明。
- 输入框默认选中“新建书单”，键盘弹出时面板跟随上移，不遮挡按钮。
- 主按钮使用品牌蓝，次按钮为白底蓝字。
- 用户点取消或下滑关闭时，A、B 沿原路径回弹，数据库不发生变化。

### 7.3 确认后的聚合动画

- 点“合成书单”后，先提交原子数据库事务；事务成功后才播放完成动画。
- A、B 的封面预览在 320ms 内分别移动到新书单左上、右上槽位。
- 白色书单容器由 B 的原位置展开，其余卡片平滑补位。
- 动画结束后显示 `共 2 本`，产生一次轻触感。
- 事务失败时不播放完成动画，恢复 A、B 原位并显示非阻塞错误提示。

### 7.4 加入已有书单

- 漫画拖到已有白色书单中央时，书单的四格轻微分开，提示将放入下一可见槽。
- 松手后出现较短的白色确认面板：`将《漫画名》加入《书单名》？`。
- 确认后源封面缩放并飞入对应槽位；如果书单已有四本，飞入中心后四格使用 120ms 交叉淡化更新预览。
- 取消、失败和私密升级规则沿用新建书单逻辑。

## 8. 统一动效系统

### 8.1 时长层级

| 层级 | 时长 | 使用场景 |
|---|---:|---|
| 即时反馈 | 90～140ms | 按下、边框、图标、选中 |
| 微动效 | 150～190ms | 卡片抬升、页码显隐、工具栏显隐 |
| 布局移动 | 220～260ms | 网格让位、排序、面板开合 |
| 形态变换 | 280～340ms | 进入书单、合组聚拢、图片 Hero |
| 意图停留 | 550ms | 合组候选武装，不属于播放动画 |

### 8.2 曲线

- 进入与让位：`Cubic(0.20, 0.00, 0.00, 1.00)`。
- 离开与淡出：`Cubic(0.40, 0.00, 1.00, 1.00)`。
- 取消回弹：阻尼弹簧，禁止夸张弹跳，最多一次 2% 回弹。
- 连续拖动位置必须直接跟手，不给指针位置加缓动；只对周围卡片和形态变化做动画。

### 8.3 动效状态表

| 动作 | 开始 | 进行中 | 结束 |
|---|---|---|---|
| 打开阅读器 | 白色底立即出现 | 内容 180ms 淡入 | 不允许黑屏闪烁 |
| 显示控制栏 | 顶部下移 8dp | 160ms 淡入 | 覆盖原图 |
| 长按卡片 | 触感一次 | 150ms 抬升 | 跟手拖动 |
| 排序 | 显示插入线 | 邻项 220ms 让位 | 松手保存并降落 |
| 合组候选 | 淡蓝边框 | 550ms 后四格预演 | 松手进入确认 |
| 取消合组 | 保留原占位 | 240ms 回原位 | 数据不变 |
| 确认合组 | 事务成功 | 320ms 聚拢 | 显示书单与数量 |
| 打开书单 | 白卡抬升 | 280ms 容器扩展 | 子项分批出现 |
| 关闭书单 | 子项收束 | 260ms 回到卡片 | 主书架可操作 |

### 8.4 减少动态效果

- 尊重 Android“移除动画”与 Flutter `MediaQuery.disableAnimations`。
- 开启减少动态效果后：取消缩放、Hero 和弹簧，只保留 80ms 淡入淡出与即时位置更新。
- 动效不能成为完成操作的唯一提示；文字、边框、图标和触感必须仍能表达状态。

## 9. 性能和工程约束

- 目标为 60fps：普通设备 UI 帧与 Raster 帧均尽量低于 16.7ms。
- 拖动过程只使用已生成缩略图，不解码原图、不读取压缩包、不执行网络请求。
- 拖动反馈复用现有卡片尺寸和缩略图缓存，不创建新的大位图副本。
- 不在整个书架上使用实时高斯模糊；白色浮层优先使用不透明度和轻阴影。
- 同一时刻最多运行动画：拖动卡 1 个、目标卡 1 个、受影响网格项一组；屏外卡片不动画。
- 书架 600 个节点时，拖动边缘自动滚动、定位、内存和帧率必须单独测试。
- 合组动画与数据库事务解耦：先验证事务成功，再播放最终聚合；不得用动画掩盖写入失败。

## 10. 数据、升级与隐私

- 本轮书架视觉和动效不改变漫画、封面、书单成员或书架顺序的数据语义。
- 预计只新增一个阅读偏好：`readerSurfaceMode = paper | night`；若因此升级 schema，必须先生成新的数据库快照。
- V1.4 已有 `imageGap`、亮度、阅读位置、书签、私密状态、挂载授权和书单顺序全部保留。
- 升级 APK 不移动、不删除、不压缩、不重编码原图。
- 动效只读取本地缩略图，不上传图片、标题、书单或阅读记录。
- 私密漫画和私密书单在锁定状态下，动画层也不能短暂泄露真实封面。

## 12. 验收清单

### 12.1 阅读器

- [ ] 从详情点“继续阅读”，第一帧就是 `paper/surface`，无黑屏闪烁。
- [ ] 本地漫画和挂载漫画的顶部栏、页码、滑轮、加载、错误和设置颜色一致。
- [ ] 控制栏白底蓝色，出现/隐藏不推动漫画位置。
- [ ] 页码胶囊为白底蓝字，底部仍无横向 Slider。
- [ ] 右侧滑轮空闲时完全不可见，触碰后显示，松手约 1.1 秒隐藏。
- [ ] 放大页默认白底；用户可主动切换黑底。
- [ ] 系统返回与顶部返回继续保存阅读位置。

### 12.2 书架与书单

- [ ] 360dp 宽手机保持三列，左右 16dp、列间 14dp、行间 24dp。
- [ ] 漫画标题最多两行；普通漫画与书单总高度一致。
- [ ] 白色书单内部固定四槽，0～4 本、超过 4 本和私密锁定状态均正确。
- [ ] 根书架和书单内部使用相同三列密度。
- [ ] 进入/退出书单存在连续容器过渡，系统返回仍只回主书架。
- [ ] 600 个节点的滚动、拖动和内存没有明显退化。

### 12.3 拖动与合组动效

- [ ] 长按后卡片从原尺寸平滑抬升，不突然缩成固定大小。
- [ ] 拖到边缘只排序，其他卡片用 220～260ms 平滑让位。
- [ ] 拖到中央时目标不剧烈缩小，550ms 后出现四格合组预演。
- [ ] 松手出现动态白色确认面板，能看到合组后的真实四宫格预览。
- [ ] 取消时两本漫画沿原路径复位，顺序和归属不变。
- [ ] 确认后事务先成功，封面再聚拢进新书单；失败时不出现伪完成动画。
- [ ] 加入已有书单、书单整体排序、书单内排序和拖回主书架仍可用。
- [ ] 系统关闭动画时功能完整，只减少运动，不减少反馈。

### 12.4 升级保护

- [ ] 从正式 V1.4 APK 使用 `adb install -r` 覆盖升级，不卸载、不清数据。
- [ ] 漫画数量、原图 SHA-256、书单成员/顺序、私密状态、挂载源、书签和阅读进度不变。
- [ ] 新增偏好具有明确默认值和升级快照；回退文档同步更新。
- [ ] Android 实机录制打开阅读、拖动排序、取消合组、确认合组、进入/退出书单五条完整动画。

## 13. LOOP 实施顺序

下一轮获得“开始实施”指令后，按以下顺序循环，不以静态截图代替真实手势：

1. 建立 `backup-pre-v1.5-*` 回退标签并保存 V1.4 覆盖升级基线数据。
2. 先写失败测试：阅读器无硬编码黑色、白蓝组件共享、卡片实际尺寸拖动、确认面板与取消不变。
3. 抽取本地/挂载阅读器共享白蓝控制组件，完成第一类验收。
4. 重构三列栅格尺寸和白色书单，完成 0/1/2/4/5+ 本状态。
5. 建立统一 Motion Token，完成抬升、让位、候选、取消、确认和进出书单。
6. 做 600 节点性能测试、减少动态效果测试和私密封面泄露测试。
7. 执行 `flutter analyze`、全部测试和 Android 实机手势录制。
8. 用 V1.4 正式 APK 原位升级候选包，核对数据库、原图哈希与挂载记录。
9. 用户验收后再构建 Release APK、签名校验、上传私人 GitHub，并从 Release 反向下载复核。

任一环节出现突跳、黑屏、封面泄露、事务先后颠倒或旧数据变化，都回到对应失败用例继续 LOOP。

## 14. 明确不接受的伪完成

- 只把阅读器背景从黑色改成白色，但设置、放大页、页码和挂载阅读器仍是黑色。
- 只给卡片增加 `AnimatedScale`，但拖动反馈仍突然变成固定尺寸。
- 只延长动画时间，实际网格仍瞬间跳位。
- 合组仍使用通用系统对话框，只把它换成白色。
- 白色书单只是一张蓝底四宫格换成白底，没有统一标题、数量、菜单和卡片高度。
- 复制参考应用的橙色、广告或导航，而没有保持拾画阁自己的蓝白语言。
- 动效完成了，但取消会改变数据、失败仍显示成功聚合，或升级破坏 V1.4 数据。
- 只通过 Widget 测试，没有 Android 真机/模拟器的实际拖动与页面过渡验收。

## 15. 最终定义

V1.5 完成后，拾画阁的框架仍然是用户认可的那一版，但三个体验会明显不同：

- 点“继续阅读”后进入的是与书架一致的白蓝画纸空间，不再像切换到另一个黑色应用。
- 长按、拖动、换位、合组和返回都具有连续的空间关系，卡片不会突然缩小或瞬移。
- 书单在主书架中是一张整齐、轻盈、能看见真实内容的白色四宫格集合卡，并与普通漫画共享同一套三列秩序。
