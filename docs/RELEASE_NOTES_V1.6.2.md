# 拾画阁 v1.6.2 发布说明

**发布日期**：2026-09-16
**版本号**：1.6.2+9（versionCode 9）
**提交**：`633b12a`
**资产**：`shihuage-v1.6.2-android.apk`

---

## 一句话概括

这一版把**导入压缩包的三个缺陷**修掉了（含"外层有封面图就丢掉内层漫画"和
"只导入第一本"），并统一了阅读器、书架与动效的视觉规范。

---

## 重要修复

### 1. 嵌套压缩包现在能导入了

外层 ZIP 里每话一个 CBZ（例如 `1.zip` 内含
`神探 Sherlock/连载_第1话 （31P）_30a480.cbz`）以前会直接被拒绝，
提示"压缩包中没有可导入的图片"。

原因：扫描只找最外层的图片，而 `cbz` 不在图片扩展名里，于是检出 0 张就报错，
从不递归内层。**现在会逐个解出内层包并全部导入。**

**实机验证**：7 个内层包、共 **183 张全部导入成功**
（此前只导入第 1 话的 31 张就停止）。

### 2. 外层有图片时不再丢掉内层漫画

如果外层 ZIP 里放了一张 `cover.jpg`，以前扫描到图片就直接返回，
**里面的 CBZ 章节会被静默丢弃**。现在外层图片与内层包都会处理，
按它们在压缩包中的先后顺序合并。

### 3. "只导入第一本"已修复

以前第一个压缩包失败后，**后续所有压缩包都不会再被尝试**——
这就是"7 本只进去 1 本"的直接原因。现在失败会被记录，然后继续处理其余压缩包。

### 4. 导入失败的原因现在看得见

以前扫描阶段的问题（内层包损坏、嵌套层级过多、数量超限）
只记录在内部、**界面上完全看不到**，用户会看到"导入完成"。

现在结果对话框区分三种情况，并逐条列出是哪个文件、什么原因：

- **压缩包导入完成**
- **部分导入成功**（有成功也有失败）
- **压缩包导入失败**

### 5. 重试不再重复导入

失败后点"重试"以前可能把**已经成功的压缩包再导一遍**（在"保留重复"模式下会重复追加内容）。
原因是同一外层包解出的内层包共用一个编号。现在每个包有独立标识，重试只处理失败的那些。

## 界面与交互

### 拖动排序

- **拖动时只带封面图**，不再把下面的名称和数据一起拖起来。
- 拖到卡片边缘会显示**插入位置指示**（蓝色竖线），能预判落点。
- 卡片让位时长对齐规范（220ms）。

### 阅读器

- **页码胶囊可以点击**，直接输入页码跳转；超出范围会修正并告知改成了第几页，
  输入非数字会提示而不是无反应。
- 阅读设置面板**按用途分组**（阅读背景 / 亮度 / 版式 / 阅读辅助 / 书签）。
- 本地漫画与网络漫画**使用同一套加载状态与错误提示**；
  本地阅读器以前读取失败会一直转圈且没有说明，现在会显示原因并提供重试。

### 书架

- 主书架标题改为「我的书架」。
- 空书架时不再同时显示两个功能相同的新建入口。
- 新建/重命名时**名称为空会就地报错**，而不是点了没反应。
- 合组面板标题与按钮统一为「新建分组」；分组菜单里的删除改为「解散分组」，
  并说明"分组内的漫画回到书架，不会被删除"。

### 动效

所有动画时长集中管理，并按规范区间取值（按钮反馈 100–150ms、
工具栏 160–200ms、面板与让位 220–280ms）。
系统关闭动画时会降级为短过渡，功能不受影响。

### ⚠️ 关于签名密钥的重要说明

**本版使用与 v1.4.0 相同的密钥**（`3724690E…`），而不是 v1.6.0 / v1.6.1 的 `1F6A95C4…`。

原因：v1.6.0 与 v1.6.1 误用了另一把密钥，导致**从 v1.4.0 升级过来的用户无法覆盖安装**，
会报 `INSTALL_FAILED_UPDATE_INCOMPATIBLE`（应用未安装：软件包与现有软件包存在冲突）。

v1.6.2 已改回 v1.4.0 的密钥，**从 v1.4.0 及更早版本可直接覆盖升级**。

**升级路径实测**（在 Android 15 模拟器上真实执行）：

```
1) 安装 v1.4.0                        → Success
2) 不卸载，直接安装 v1.6.2            → Success
3) 覆盖后 versionName=1.6.2，数据保留
```

反例（说明问题确实存在）：在装有 `1F6A95C4` 密钥版本的设备上安装本包，
会得到 `INSTALL_FAILED_UPDATE_INCOMPATIBLE`。

### 各版本密钥对照（实测）

| 版本 | 证书 SHA-256（前 8 位） |
|---|---|
| v1.4.0 | `3724690E` |
| v1.6.0 | `1F6A95C4` ⚠️ |
| v1.6.1 | `1F6A95C4` ⚠️ |
| **v1.6.2** | **`3724690E`** ✅ |

**已装 v1.6.0 / v1.6.1 的用户**：由于这两版用的是 `1F6A95C4`，
装 v1.6.2 会提示签名冲突，需要**先卸载**（会清除应用内数据，
请先在设置里导出备份）。这是历史遗留问题，无法在不卸载的情况下跨越，
因为应用签名一旦发布就无法更改。

## 安装说明

1. **已装 v1.4.0 或更早版本**：可直接覆盖安装，数据保留。（本版已改回 v1.4.0 的密钥）
2. **已装 v1.6.0 / v1.6.1**：这两版误用了另一把密钥（`1F6A95C4`），
   安装会提示签名冲突。需要**先卸载**——会清除应用内数据，
   请先在「设置」中导出备份，装好 v1.6.2 后再恢复。
3. 首次启动后，可在「设置」中查看版本号确认为 1.6.2。
