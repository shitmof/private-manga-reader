# 私人书架 v1.2.0

这是可以使用相同签名直接覆盖 v1.1.0 的 Android 功能版。UI 继续使用原有蓝白、克制、内容优先的风格。

## 核心新增

- 书架改为三列，新增文件夹分组、拖入、批量移动、置顶、搜索、书单与私密区。
- 私密漫画和私密文件夹使用系统生物识别/设备凭据，进入后台重新锁定，私密阅读页启用 `FLAG_SECURE`。
- 编辑器支持单选、多选、全选、页码范围、批量删除、拖动、多选块移动和指定页码移动；只有点“保存”才落库。
- 本地与网络阅读器新增右侧拖动快速定位器、底部页码滑块、阅读亮度和页面书签。
- 本地漫画可按当前顺序无损导出 CBZ，保存到手机/云盘或调用 Android 系统分享。
- 在 Android 文件管理器点击 CBZ/ZIP/CBR/RAR/CB7/7z/CBT/TAR，可直接用私人书架打开并自动进入导入流程。
- 完整备份可通过系统文档选择器写到 App 私有目录之外，卸载后仍保留；恢复前仍会自动创建安全备份。
- WebDAV、OPDS/Komga/Kavita、SMB/NAS 挂载保留只读，新增连接状态、最后成功/同步时间、脱敏错误与重新认证。

## 数据与升级

- 包名不变：`com.shitmof.private_manga_reader`。
- 版本：`1.2.0+3`。
- 签名证书 SHA-256 与 v1.1.0 一致：`3724690e26bae1597ad10221c10f2b2b15ade2a5bfdbaf408834dc46eaace1a5`。
- SQLite schema 从 3 增量升级到 5，升级前自动保留 `library.db.pre-v5`。
- 原图目录不移动、不覆盖、不重编码。
- 实测 v1.1.0 原位覆盖后，旧漫画名称、页数和 3 个原图 SHA-256 全部不变。

## 边界

- 远程压缩包是按需下载到受控缓存后阅读，不是服务器端逐页流式解压。
- 完整备份当前未加密，应保存在用户自己控制的手机、云盘或 NAS。
- 为保持与已发布版本的升级兼容，v1.2.0 延续现有签名证书；后续版本必须持续安全保留同一密钥。
