# 拾画阁 v1.3.0

这是可使用相同签名直接覆盖 v1.2.0 的 Android 正式版。App 已更名为“拾画阁”，包名保持不变，原有漫画、分组、顺序、封面、阅读进度、书签、书单和备份不会因升级被重置。

## 核心新增

- 使用新的“多层画册 + 图片 + 书签”图标，桌面、任务切换页和 App 内名称统一为“拾画阁”。
- 主书架保持三列；漫画和分组成为可混合排序的书架节点，支持整理模式拖动和漫画拖入分组。
- 分组在主书架及移动弹层中统一显示带外框的固定 2×2 四宫格封面；不足四本保留空格位，私密分组不泄露真实封面。
- 书单、分组、私密区和搜索状态使用统一内部返回逻辑，Android 侧滑/系统返回优先回到书架根状态。
- 设置页收起常驻大滑杆，阅读间距改为点击后调整；主书架快速滚动和右上操作区互不遮挡。
- 新增 Android SAF 本地原地挂载：用户选择图片目录或包含图片目录、ZIP/CBZ 的父目录后，可直接建立只读索引和阅读，不复制原文件。
- ZIP/CBZ 页面使用随机访问并受 120 项/96 MiB 缓存上限约束；阅读进度仍只保存在本机。

## 导入与存储边界

- 普通导入继续支持 ZIP/CBZ、CBR/RAR、CB7/7z、CBT/TAR，并保留原顺序、原字节与 SHA-256 校验。
- SAF 原地随机读取当前支持图片目录与 ZIP/CBZ；其他压缩格式继续使用普通导入。
- 原地挂载依赖 Android 系统目录授权。原目录被移动、授权被撤销、App 数据被清除或换机后，需要重新选择目录。
- 完整备份会保存挂载索引和阅读记录，但不会复制外部原文件；恢复后用“重新选择目录”恢复关联。
