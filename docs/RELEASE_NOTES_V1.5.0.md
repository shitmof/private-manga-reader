# 拾画阁 v1.5.0 发布说明

发布日期：2026-09-01  
Android 版本：`1.5.0+6`

## 本次完成

### 白蓝阅读器

- 本地漫画与挂载漫画默认使用统一的白色画布、白色控制栏和拾画阁蓝色操作图标，不再以黑色作为默认阅读背景。
- 顶部控制栏、页码胶囊、加载状态、错误状态、放大页和右侧快速定位器统一为白蓝视觉。
- 新增独立的“画纸 / 夜间”阅读画布偏好；它不跟随应用深色主题强制变黑，升级后默认仍为画纸。
- 阅读页采用 240ms 白底淡入缩放转场，避免进入时出现黑屏闪烁；开启 Android 减少动态效果后降级为短淡入。
- 保留 V1.4 的 48dp 隐形纵向定位热区：空闲完全不可见，触摸后出现，松手约 1.1 秒后自动隐藏。

### 三列书架与动态白色书单

- 360dp 手机宽度保持三列，左右留白 16dp、列间距 14dp、行间距 24dp。
- 封面统一为 0.72 宽高比；标题支持两行，标题、元信息和菜单使用固定节奏，普通漫画与书单保持等高。
- 书单改为白色 2×2 四宫格容器：1dp 结构线、轻阴影、8dp 内边距和 4dp 槽位间距；不足四本使用淡蓝空槽。
- 点击进入/退出书单使用 280ms 淡入缩放过渡；系统返回仍先回主书架，不直接退出应用。

### 拖动、合组与确认

- 拖动反馈直接采用原卡片实际宽高，150ms 抬升至 1.035 倍，不再突然变成固定尺寸。
- 漫画进入合组候选时，目标卡片改为轻微放大和淡蓝呼吸边框，不再缩小到 0.92。
- 两本漫画合组使用动态白色底部面板，直接展示真实四宫格预览、名称输入和“合成书单”操作。
- 漫画加入已有书单也使用白色确认面板；取消不改顺序或归属，确认后才执行数据库事务。
- 根书架排序、边缘自动滚动、书单整体排序、书单内排序和拖回主书架继续保留。

### 升级与数据保护

- SQLite schema 从 7 增量升级到 8，仅增加阅读画布偏好，不移动、不删除、不压缩、不重编码原图。
- 首次升级前自动创建 `library.db.pre-v8` 数据库快照。
- 包名、`versionCode` 递增规则和签名证书保持不变，可直接覆盖安装 V1.4。
- GitHub 仓库与 Release 不包含用户导入的漫画、数据库、备份、挂载凭据或阅读记录。

## 已知边界

- 书单进出已具备淡入缩放和连续状态切换，但尚未实现封面逐格 Hero 形态变换；本版优先保证稳定、数据正确和减少动态效果兼容。
- 网格在松手后的最终数据顺序会立即刷新；拖动抬升、目标候选和确认面板已平滑化，但不是完整的物理弹簧重排引擎。
- SAF 原地随机读取覆盖图片目录与 ZIP/CBZ；其他漫画压缩格式继续走普通无损导入流程。
- 当前没有用户真实 SMB/NAS 账号，不宣称兼容所有 NAS 型号。
- Android 升级不会替代外部备份；卸载、清除应用数据或换机前仍应导出 `.mangabackup`。
