# 拾画阁 v1.6.3

版本：`1.6.3+10`。本版重点为导入、备份、私密保护和阅读交互修复，保留白蓝 UI 与原有书架布局。

## 改进

- 混合包、内层坏包、失败重试按实际来源处理，健康包不被静默漏掉；重试保留实际顺序，长篇失败批次原子回滚。
- 修复已有原图损坏后重导仍误报成功、无效图片以零尺寸入库；重导可修复原图并保留稳定引用。
- 单本统一支持最多 **10000 页**，超过上限在导入前提示，不再导到一半才发现容量不够。
- 备份逐文件流式写入，增加备份/恢复空间预检、输入中断清理和恢复失败回滚；保留 v1～v4 备份兼容。
- 私密分组内漫画继承截屏保护，导出前验证身份；保护严格申请/释放配对。
- 阅读间距变化保留当前页内位置，同一设置面板内主题立即刷新。
- 新增本地空间分类、挂载缓存清理和可调整预算，默认 1 GiB，可选择 256 MiB～4 GiB；缓存同时限制字节数和文件数。
- SAF 同 URI 文件更新不再永久复用旧缓存；修改时间未知的提供者在刷新时重新索引。
- 修正官方签名说明并固定发布渠道证书。

- 包名不变，数据库仍为 schema 8，备份仍导出 v4、读取 v1～v4。
- 原图不压缩、不重编码，用户漫画和备份不上传到 GitHub。
