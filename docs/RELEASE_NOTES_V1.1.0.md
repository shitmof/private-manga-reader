# 私人书架 v1.1.0

这是可以直接覆盖 v1.0.0 安装的 Android 功能版本，UI 风格保持不变。

## 新增

- CBZ/ZIP、CBR/RAR、CB7/7z、CBT/TAR 整包导入。
- 多压缩包按选择队列连续追加，包内按 `ComicInfo.xml` 或数字自然顺序排列。
- WebDAV、OPDS/Komga/Kavita、SMB/NAS 只读网络书库；阅读进度只保存在本机。
- 网络漫画独立缓存、单本清缓存、重新扫描、更新凭据与解除挂载。
- 书架回收站、恢复、永久删除和页面多选删除。
- v1→v3 数据库增量迁移与迁移前自动快照。
- 完整备份 v2：保存网络书源和本地阅读进度，不保存网络页面缓存与密码。

## 升级与隐私

- 包名与 v1.0.0 相同：`com.shitmof.private_manga_reader`。
- 签名证书与 v1.0.0 相同，可原地覆盖安装，不需要卸载。
- 升级验证中旧漫画名称、原图、页数、体积和 SHA-256 均保持不变。
- 网络文件始终只读；密码存入 Android 安全存储，不进入数据库、备份或 GitHub。
