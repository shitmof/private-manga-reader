# 拾画阁 v1.4.0 发布说明

发布日期：2026-08-31  
Android 版本：`1.4.0+5`

## 本次完成

### 主书架拖动与书单

- 主书架保持现有蓝白、克制、三列布局，不进行整体换肤。
- 不必进入“整理书架”：直接长按漫画或书单即可拖动，靠近屏幕上下边缘时自动滚动，松手保存根书架顺序。
- 漫画拖到另一漫画中央并停留约 550ms 后进入合组候选；松手弹出“合成书单”，取消不改数据，确认后原子创建书单。
- 新书单以固定 2×2 四宫格小框占用一个书架格位，显示最多四本真实封面与总数。
- 漫画拖到已有书单会先询问“加入书单”，确认后才移动。
- 书单自身可在主书架参与排序；书单内部可直接拖动漫画调整顺序。
- 在书单内部拖动时，顶部才出现“拖到这里移回主书架”目标；松手后漫画回到主书架，静止时不占界面。
- 系统返回或侧滑返回从书单内部先回主书架，不直接退出应用。

### 阅读器

- 新安装默认使用 0dp 无缝图片间距；升级时仅把旧版本内置默认值 10dp 迁移为 0dp，用户主动选择的其他值保持不变。
- 删除底部横跨屏幕的进度 Slider，只保留紧凑页码胶囊。
- 右侧使用 48dp 隐形定位热区：空闲时轨道、滑块和提示完全不可见，触碰或拖动后才显示，松手约 1.1 秒后自动隐藏。
- 按住右侧任意热区即可从顶部一次拖到长漫画末页，拖动时显示当前页/总页数。
- 本地漫画与挂载漫画使用相同阅读交互，返回时保存阅读位置。

### 升级与数据保护

- SQLite schema 从 6 增量升级到 7，只迁移阅读间距偏好，不移动、不删除、不重编码漫画原图。
- 升级前自动创建 `library.db.pre-v7` 数据库快照。
- APK 包名和签名证书保持不变，可从 v1.3.0 使用系统覆盖安装直接升级。
- GitHub 仓库和 Release 只保存源码、设计参考和 APK，不包含用户导入的私人漫画。

- `flutter analyze`：0 个问题。

## 已知边界

- SAF 原地随机读取覆盖图片目录与 ZIP/CBZ；CBR/RAR、CB7/7z、CBT/TAR 继续走普通无损导入流程。
- Android 的目录授权由系统文件提供器维护。移动目录、撤销授权、清除 App 数据或换机后，需要重新选择目录。
- WebDAV 与 OPDS 已有真实服务链路验证；当前环境没有用户的真实 SMB/NAS 账号，不宣称兼容所有 NAS 型号。
- `.mangabackup` 是卸载/换机后的完整数据找回方式；升级 APK 不会代替备份，也不会把用户原图上传到 GitHub。
